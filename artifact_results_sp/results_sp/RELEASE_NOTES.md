# artifact_results_sp Release Notes

## v1

This artifact package contains:

- Source-code-facing configs and scripts for quick and full reproduction.
- Processed data retained under `data/processed/`.
- Raw, normalized, and summary result CSVs organized by paper figure.
- Manifests and validation report.
- Metric policy separating AUC and cost sources.
- Documentation for artifact claims, datasets, runtime expectations, anonymization, and Alibaba Cloud reruns.

The canonical normalized table is `normalized/master_long.csv`. The canonical paper summaries are in `summaries/`.
